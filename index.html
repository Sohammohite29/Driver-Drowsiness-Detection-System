About the System

The Smart Driver Safety Monitoring System is a computer vision based safety application designed to monitor a driver's eye activity in real time. The system calculates the Eye Aspect Ratio (EAR) using facial landmarks. When prolonged eye closure is detected, the system identifies a drowsiness event and activates an audio warning.

Real-Time Monitoring

The camera continuously monitors the driver's face and eye activity.

Drowsiness Detection

Eye Aspect Ratio is used to identify prolonged eye closure.

Audio Warning

An audible alarm helps regain the driver's attention during drowsiness.
